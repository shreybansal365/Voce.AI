# Contributing to Voce.AI

Thank you for your interest in contributing to **Voce.AI**—the future of spoken intelligence. To maintain the "Immaculate" quality of this platform, we adhere to strict engineering and design standards.

## 🎨 Design Integrity
- **Lavender Glass**: All UI components must adhere to the high-fidelity Lavender Glass design system.
- **Color Space**: Utilize `oklch` for all color definitions to ensure perceptual uniformity.
- **Interactions**: Maintain 32px backdrop-blur and 300ms transition curves for all glass utilities.

## 🛠️ Engineering Standards
- **Next.js 15**: Use the App Router exclusively.
- **Convex**: Ensure all data persistence is handled through Convex mutations and queries with proper validation.
- **Observability**: New API routes must include Prometheus metrics instrumentation.

## 🚀 Pull Request Process
1.  **Issue First**: Please open an issue to discuss significant architectural changes before submitting a PR.
2.  **Linting**: Ensure all code is cleanly formatted.
3.  **Documentation**: Update the "Immaculate" README if your feature introduces new technical requirements.

By contributing, you agree that your code will be licensed under the **MIT License**.
